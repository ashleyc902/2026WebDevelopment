CSS

CSS stands for Cascading Style Sheet. It is used to make the presentation, layout, and how a doctument written from HTML looks visually. Without CSS, a web page would have no color and just be a plain document.

Javascript

JavaScript is a programming language that adds dynamic behavior into a webpage. It recalculates data and loads updates. It also serves as one of the core technologies alongside HTML and CSS.

jQuery

jQuery is used to simplify lines of code. It can handle custom animations and bugs on different browsers. It can be used to easily modify, add, or delete HTML elements and CSS styles.
